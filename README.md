# Olympics Data Analysis Dashboard 🏅

## Project Overview
This project presents an interactive Olympics Data Analysis Dashboard created using Tableau. It explores Olympic history through athlete participation, medal achievements, sports performance, and athlete demographics.

## Objectives
- Analyze male and female participation across Olympic years.
- Explore the relationship between athletes' height and weight.
- Compare athlete participation in Summer and Winter Olympics.
- Identify the top 10 countries by total medals.
- Analyze the top 10 sports by total medals.
- Understand the age, weight, and height distributions of Olympic winners.

## Dashboard Features
- **Gender Participation:** Male vs. female participation over the years.
- **Height and Weight Correlation:** Relationship between athletes' height and weight.
- **Year and Season Analysis:** Athlete participation in Summer and Winter Olympics.
- **Country Medal Analysis:** Top 10 countries based on total medals.
- **Sports Performance:** Top 10 sports by total medals.
- **Age Distribution:** Age analysis of Olympic winners.
- **Weight Distribution:** Distribution of winners by weight.
- **Height Distribution:** Distribution of winners by height.

## Tools and Technologies
- Tableau – Data visualization and dashboard development.
- Microsoft Excel – Dataset storage and preparation.
- Olympics Athlete Events Dataset – Historical Olympic athlete data.

## Dataset
The dataset contains information about Olympic athletes, including their age, gender, height, weight, country, sport, season, year, and medal achievements.

## Key Insights
- Explore changes in male and female participation over time.
- Compare medal achievements across countries.
- Identify sports with high medal counts.
- Understand the physical characteristics and age distribution of Olympic winners.

## Dashboard Preview
The dashboard includes interactive charts, comparison graphs, and distribution plots for exploring Olympic data.

## Conclusion
This project demonstrates how data visualization can transform historical Olympic data into meaningful insights. It helped develop practical skills in data analysis, dashboard design, and visual storytelling using Tableau.
